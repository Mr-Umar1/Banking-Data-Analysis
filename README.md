Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on banking customer transaction and demographic datasets. The objective is to identify key trends, customer behavioral patterns, risk distribution, and factors affecting customer retention using Python and data analytics libraries.
Programming Language: Python
  Data Processing: Pandas, NumPy
  Data Visualization: Matplotlib
* Key Analysis & Steps Performed
1. Data Cleaning & Preprocessing: Handled missing values, incorrect data types, duplicate records, and outliers.
2. Exploratory Data Analysis (EDA):
   Demographic distribution analysis (Age, Gender, Location).
   Account balance vs. credit score trends.
   Transaction volume and active membership status evaluation.
   Data Visualization:** Generated bar charts, correlation heatmaps, box plots, and histograms to uncover insights.
